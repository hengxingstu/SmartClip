# SmartClip Desktop Shell

This directory contains the Electron desktop shell for SmartClip. It starts the local Java backend, loads the built frontend, keeps the app alive in the system tray when the window is closed, and packages the frontend, backend, and slim JRE into a Windows installer.

## Runtime Layout

Place build artifacts under:

```text
desktop/
|-- app/
|   |-- frontend-dist/         # Built frontend, must include index.html
|   |-- backend/               # Spring Boot executable jar
|   `-- runtime/
|       `-- win-jre/           # Slim JRE generated by jlink, must include bin/java.exe
|-- assets/                    # App icon source and Windows .ico
|-- main.js                    # Electron main process
|-- preload.js                 # Renderer preload bridge
`-- scripts/                   # Build helper scripts
```

The packaged app prefers:

```text
desktop/app/backend/smartclip-backend.jar
desktop/app/frontend-dist/index.html
desktop/app/runtime/win-jre/bin/java.exe
```

`npm run prepare:app` copies the latest backend jar from `../target/*.jar` into the stable backend filename and copies the frontend build into `app/frontend-dist`.

## Development

Run the Spring Boot backend and Vite frontend first, then start Electron against the dev server:

```powershell
cd desktop
npm install
npm run dev:web
```

`dev:web` loads `http://localhost:5173` and expects the backend on `127.0.0.1:8080`.

## Local Packaging

From the repository root:

```powershell
$env:JAVA_HOME='E:\TOOL\Env\Java\jdk-17.0.8'
$env:Path="$env:JAVA_HOME\bin;$env:Path"

cd frontend
npm install
npm run build

cd ..
mvn package

cd desktop
npm install
npm run prepare:app
npm run build:jre
npm run verify:layout
npm run pack
```

Run the unpacked app:

```text
desktop/dist/win-unpacked/SmartClip.exe
```

Build the installer:

```powershell
npm run dist
```

The installer output is:

```text
desktop/dist/SmartClip-Setup-1.0.0.exe
```

## Slim JRE

Generate the bundled JRE with:

```powershell
cd desktop
npm run build:jre
```

The script auto-detects the newest jar in `../target/*.jar`. To override it:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-jre.ps1 -JarPath ..\target\your-app.jar
```

## Tray Behavior

- Closing the main window hides it to the tray.
- Clicking or double-clicking the tray icon reopens the window.
- The tray menu can reopen SmartClip, restart the backend, or fully exit the app.
- Only the tray `Exit` action fully stops Electron and the Java backend.

## Data Location

The desktop app stores user data under Electron's user-data directory, typically:

```text
%APPDATA%\SmartClip\
```

The SQLite database is stored there instead of inside the install directory, so the app can run from read-only install locations.
